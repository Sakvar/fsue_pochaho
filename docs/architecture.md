# Архитектура прототипа

Главный принцип: симуляция не зависит от Phaser.

```text
src/
  content/              # текстовые названия и будущие JSON-каталоги контента
  game/                 # Phaser-сцены, ввод, рендер
  simulation/           # чистое игровое ядро
```

## Simulation

`src/simulation` хранит состояние мира и игровые системы:

- `types.ts` — типы сущностей;
- `createInitialWorld.ts` — стартовая карта и стартовые сотрудники;
- `pathfinding.ts` — поиск пути по сетке;
- `simulation.ts` — основной tick, генерация задач, назначение сотрудников, выполнение работ.

Эта часть должна оставаться тестируемой без браузера и без Phaser.

## Game

`src/game` отвечает только за отображение и ввод:

- рисует карту, стены, помещения, сотрудников и станки;
- показывает состояние задач;
- передаёт команды игрока в simulation-слой.

## Следующий технический шаг

Перед усложнением игры стоит вынести рецепты, профессии, помещения и станки в data-driven формат, чтобы добавление контента не требовало переписывать симуляционные системы.
