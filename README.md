# ФГУП «ПОЧАХО»

Первый технический прототип браузерного симулятора предприятия: маленькая карта завода, сотрудники, задачи, станки, контракты с бюджетом и автономное выполнение заказа.

Игра пока намеренно простая: цель прототипа — проверить, интересно ли наблюдать за тем, как сотрудники пытаются выполнить принятый контракт в живой производственной системе.

## Быстрый старт

```bash
npm install
npm run dev
```

Требуется Node.js 20.19 или новее. Рекомендуемая версия записана в `.nvmrc`.

Сборка и тесты:

```bash
npm test
npm run build
```

## Что уже есть

- Vite + Phaser + TypeScript.
- Отдельное симуляционное ядро без зависимости от Phaser.
- Карта одного этажа с цехами, складом и административной зоной.
- Контракты: принять → аванс в бюджет → произвести → выплата и грант (или штраф за срыв).
- Бюджет: ежедневная зарплата, платные запчасти, разовая модернизация Р-17.
- Найм из пула кандидатов; архетипы «молодой специалист» и «дедок».
- Сотрудники с навыками, окладом, энергией, моралью, стрессом и сменами.
- Автоматическая очередь задач: металл → резка → сборка → ОТК → склад.
- Станок резки изнашивается; ремонт и ТО требуют запчастей.
- ОТК с браком, скрытыми дефектами, переделкой и списанием.
- Репутация качества; причины простоя в HUD.
- Строительство стен/дверей и зон; приоритеты и отмена нарядов.
- Смены и посты; авто-отдых при критической усталости (без ручной кнопки).

## Управление

- ЛКМ по клетке — осмотр или действие выбранного инструмента.
- Панель **Контракты** — принять предложение (один активный).
- Панель **Кадры** — нанять кандидата за плату.
- В личном составе: клик → смена / пост в инспекторе.
- «＋ Запчасти» — купить запчасти за бюджет.
- «⬆ Модерн. Р-17» — разовая модернизация надёжности.
- «Списать брак», «Авария Р-17», пауза и скорость — как прежде.
