# ФГУП «ПОЧАХО»

Первый технический прототип браузерного симулятора предприятия: маленькая карта завода, сотрудники, задачи, станки, материалы, поломки и автономное выполнение производственного заказа.

Игра пока намеренно простая: цель прототипа — проверить, интересно ли наблюдать за тем, как сотрудники пытаются выполнить заказ в живой производственной системе.

## Быстрый старт

```bash
npm install
npm run dev
```

Требуется Node.js 20.19 или новее. Рекомендуемая версия записана в `.nvmrc`.

Сборка и тесты:

```bash
npm test
npm run build
```

## Что уже есть

- Vite + Phaser + TypeScript.
- Отдельное симуляционное ядро без зависимости от Phaser.
- Карта одного этажа с цехами, складом и административной зоной.
- Сотрудники с профессиями, навыками, энергией, моралью, стрессом и сменами.
- Автоматическая очередь задач: принести металл, резать заготовку, перенести, собрать изделие, сдать на склад.
- Станок резки изнашивается; ремонт и ТО требуют запчастей и пишутся в журнал.
- ОТК с вероятностным браком, скрытыми дефектами, переделкой и списанием.
- Репутация качества падает при отгрузке скрытого брака.
- Заказ имеет срок и итоговый статус; невыполнимое увеличение плана отклоняется.
- Заблокированные работы и причины простоя видны в HUD.
- Строительство стен и дверей, зоны хранения/работы/запретные, пересчёт маршрутов.
- Ручные приоритеты нарядов, отмена задач и перепланирование заторов.
- Смены, отдых, больничные, рост навыков, личные особенности и назначения на посты.
- HUD с ресурсами, личным составом, задачами, журналом событий, паузой и скоростью.

## Управление

- ЛКМ по клетке — осмотр или действие выбранного инструмента.
- Панель инструментов — стена, дверь, снос, зоны.
- В личном составе: клик по сотруднику, затем смена / пост / отдых.
- В нарядах: ↑/↓ меняют приоритет, × отменяет задачу.
- «Перепланировать наряды» — сбрасывает заблокированные задачи в очередь.
- Кнопка «+ заказ» — увеличить план выпуска.
- Кнопка «+ запчасти» — получить запчасти со склада снабжения.
- Кнопка «Списать брак» — вместо переделки отправить изделие в лом.
- Кнопка «сломать резак» — вручную вызвать аварию для проверки ремонтного цикла.
- Кнопки скорости и паузы управляют симуляцией.
