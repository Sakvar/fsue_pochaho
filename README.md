# ФГУП «ПОЧАХО»

Первый технический прототип браузерного симулятора предприятия: маленькая карта завода, сотрудники, задачи, станки, материалы, поломки и автономное выполнение производственного заказа.

Игра пока намеренно простая: цель прототипа — проверить, интересно ли наблюдать за тем, как сотрудники пытаются выполнить заказ в живой производственной системе.

## Быстрый старт

```bash
npm install
npm run dev
```

Сборка и тесты:

```bash
npm test
npm run build
```

## Что уже есть

- Vite + Phaser + TypeScript.
- Отдельное симуляционное ядро без зависимости от Phaser.
- Карта одного этажа с цехами, складом и административной зоной.
- Сотрудники с профессиями, навыками, энергией и текущей задачей.
- Автоматическая очередь задач: принести металл, резать заготовку, перенести, собрать изделие, сдать на склад.
- Станок резки изнашивается и требует ремонта.
- HUD с ресурсами, задачами, журналом событий, паузой и скоростью.

## Управление

- ЛКМ по клетке — выбрать сотрудника или станок.
- Кнопка «+ заказ» — увеличить план выпуска.
- Кнопка «сломать резак» — вручную вызвать аварию для проверки ремонтного цикла.
- Кнопки скорости и паузы управляют симуляцией.

См. [`docs/architecture.md`](docs/architecture.md).
